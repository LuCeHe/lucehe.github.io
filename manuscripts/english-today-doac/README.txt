English Today submission notes
================================

Format they accept (not LaTeX)
------------------------------
English Today asks for Microsoft Word or Rich Text Format (.doc/.docx or .rtf),
sent through ScholarOne:

  https://mc.manuscriptcentral.com/english-today

Older notes also mention an email attachment to englishtoday@cambridge.org.
They do not list LaTeX as an accepted manuscript format.

Length
------
- Editor review: usually 2,000-4,000 words
- Peer review: up to about 6,000 words

Say clearly in the covering email whether you want editor review or peer review.

Also needed on acceptance
-------------------------
- 100-150 word biography
- a recent photograph if possible

Files in this folder
--------------------
- doac-english-today.html       styled reading version (open this in a browser)
- doac-english-today.docx       Word file built from the HTML
- doac-english-today.pdf        print version of the same layout
- doac-english-today.md         source text
- doac-english-today-formatted.docx  same as the .docx above
- doac-english-today-expanded.docx   older dump; ignore

For the journal, keep Times New Roman and double spacing if they insist.
The HTML / PDF / current .docx are the readable versions.

This article is written for editor review (about 3,500-4,000 words of main
text). Ask for peer review only if you lengthen it further toward 5,000-6,000.
